شروط الخدمة

تحدد هذه الشروط قواعد استخدام منصة Minasaty التعليمية، وحقوق ومسؤوليات الأولياء والتلاميذ والأستاذ وإدارة المنصة.

1. قبول الشروط

باستخدام Minasaty أو إنشاء حساب فيها، يقر المستخدم بأنه قرأ هذه الشروط وسياسة الخصوصية ووافق عليهما. إذا كان المستخدم تلميذًا، فيجب أن يتم استخدام الحساب بإشراف ولي أو مسؤول مناسب.

آخر تحديث: 27 أغسطس 2026.

2. طبيعة الخدمة

Minasaty منصة تعليمية تربط أستاذًا وتلاميذ وأولياءهم لتقديم حصص مباشرة ومحتوى مسجل وواجبات واختبارات وأدوات متابعة. قد تختلف المزايا المتاحة بحسب المستوى والمادة ونوع الاشتراك وحالة الحساب.

3. الحسابات والأمان

يتحمل المستخدم مسؤولية تقديم معلومات صحيحة والمحافظة على سرية بيانات الدخول. لا يجوز مشاركة الحساب أو رمز الجلسة أو كلمة المرور مع شخص آخر أو استخدام حساب شخص آخر. قد تُغلق الجلسة السابقة عند فتح الحساب من جهاز أو متصفح آخر كإجراء لحماية الحساب.

يجب إبلاغ إدارة المنصة فور الاشتباه في دخول غير مصرح به أو إساءة استخدام الحساب. لا تطلب إدارة Minasaty كلمة المرور أو PIN داخل Facebook Messenger أو أي قناة خارجية.

4. الحصص والمحتوى

يُستخدم المحتوى التعليمي لأغراض التعلم الشخصي داخل الحساب المصرح له. لا يجوز نسخ الحصص أو تسجيلها أو إعادة نشرها أو بيعها أو مشاركة روابطها أو بيانات الدخول للوصول إليها دون إذن كتابي من إدارة المنصة والأستاذ.

تتطلب الحصص المباشرة جهازًا ومتصفحًا واتصالًا مناسبًا، وقد تتأثر جودة الصوت والصورة بعوامل خارجة عن سيطرة المنصة، مثل سرعة الإنترنت أو إعدادات الجهاز أو صلاحيات الكاميرا والميكروفون.

5. الاشتراكات والدفع

يظهر نوع الاشتراك والصلاحيات في حساب المستخدم بحسب المادة والمستوى وحالة الدفع. تكون الترقية نافذة بعد نجاح الدفع الإلكتروني أو بعد مراجعة وقبول وصل الدفع اليدوي وفق الإجراءات المعروضة في المنصة.

لا ينبغي للمستخدم إرسال بيانات البطاقة أو كلمات المرور أو رموز التحقق داخل الدردشة. تخضع عمليات الدفع الإلكتروني لمزود الدفع وشروطه، وقد يُطلب إثبات المعاملة عند المراجعة.

6. الرسائل والتنبيهات

قد ترسل المنصة إشعارات داخلية أو عبر Web Push أو Telegram أو Facebook Messenger عند تفعيل القناة واختيارها. لا تضمن المنصة وصول كل إشعار بسبب إعدادات الجهاز أو المتصفح أو الشبكة أو قيود مزود الخدمة.

يخضع Facebook Messenger لموافقة المستخدم وقيود Meta على الرسائل والفترات المسموح بها. لا يُعد Messenger قناةً مضمونة لإرسال كل التنبيهات العاجلة، وتبقى القنوات الأخرى المعروضة في الحساب مستقلة عنه.

7. السلوك الممنوع

يُمنع استخدام المنصة للتحايل على الاشتراكات أو الوصول إلى محتوى غير مصرح به أو انتحال هوية مستخدم أو إرسال رسائل مسيئة أو رفع ملفات ضارة أو تعطيل الحصص أو محاولة تجاوز ضوابط الأمان. يجوز للإدارة تعليق الحساب أو تقييد الوصول عند وجود سبب أمني أو تشغيلي أو مخالفة لهذه الشروط.

8. التوافر والتعديلات

تسعى إدارة Minasaty إلى إبقاء الخدمة متاحة وتحسينها، لكنها لا تضمن عدم حدوث توقفات مؤقتة للصيانة أو الأعطال أو الأسباب الخارجة عن السيطرة. يجوز تحديث المزايا أو الواجهات أو هذه الشروط، ويُعد استمرار الاستخدام بعد نشر التحديث قبولًا للشروط المعدلة.

9. إلغاء الحساب وحذف البيانات

يمكن للمستخدم فصل القنوات الخارجية وطلب حذف الحساب والبيانات وفق الإجراءات الموضحة في صفحة حذف البيانات. قد تحتفظ المنصة بقدر محدود من السجلات عندما يكون ذلك ضروريًا للأمن أو منع الاحتيال أو المتطلبات المحاسبية والقانونية.
