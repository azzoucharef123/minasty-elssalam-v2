# اختبار الحصة العامة بالاسم الحقيقي

تم نشر الالتزام `a2bd43a` على `https://dr.africacold.fr`.

## معاينة الصفحة الرئيسية

ظهر زر الحصة العامة داخل صف أزرار الدخول الرئيسية، بتصميم أصفر وكتابة حمراء، والنص:

**الدخول إلى الحصة المجانية**

وتحته:

**مباشرة الآن — أدخل اسمك الحقيقي**

الزر مرتبط بحالة الخادم ويُفعّل فقط عندما توجد غرفة عامة نشطة. لا يظهر رمز المضيف أو رابط نسخ وإرسال للزوار.

## تدفق الدخول

- الزائر يدخل من زر الصفحة الرئيسية.
- يُطلب منه الاسم واللقب الحقيقيان.
- الخادم يرفض الاسم الفارغ أو القصير أو الاسم المكون من كلمة واحدة أو الرموز والأسماء العامة.
- ينتظر الزائر موافقة الأستاذ.
- الأستاذ يرى الطلب في قائمة طلبات الحضور ويختار قبول الدخول أو رفضه.
- لا يبدأ WebRTC ولا المايك ولا الدردشة للزائر قبل القبول.
- تم إزالة شرط Chrome-only؛ يتم الاتصال بالمتصفحات الحديثة التي تدعم RTCPeerConnection، مع رسالة توافق عند غياب الدعم.
